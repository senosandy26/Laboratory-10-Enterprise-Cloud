# **REFLECTION

Laboratory Activity 10 was very useful for our group in the application of the concepts and techniques that we acquired in the laboratory sessions of Cloud Computing. In this activity, we were able to collaborate on creating and setting up a multi-tier application with Ubuntu Server, Docker, Docker Compose, WordPress, and MySQL.

We learned as a group how to deploy separate services in containers and how to connect them together so that they can be used as an application. We also realized that persistent storage was important for maintaining data availability and security even during the restart of containers. We learned how to set up firewall rules and automate database backup procedures to understand the benefits of security and automation in reliable server management.

We faced problems that needed to be solved through teamwork, communication, and problem-solving throughout the activity. Collaborating on tasks and helping each other helped us to get a better insight into the various set-ups and solve problems. We learned that cooperation, patience and planning are essential in order to be successful in the deployment.

In general, this lab activity helped in building our knowledge of cloud technologies, containerization, Linux administration, database management, and network security. It also helped us understand the value of teamwork to create a shared objective. This experience gave us hands-on experience in the use of practical skills that we could apply in future IT projects and made us ready to deal with similar situations in a real working environment with cloud computing.
